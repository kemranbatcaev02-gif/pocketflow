# Участие в разработке PocketFlow

Мы приветствуем предложения по улучшению, отчеты об ошибках и новые примеры рабочих процессов!

## Требования:
- Go 1.22 или новее.
- Чистый CGO (`CGO_ENABLED=0`).
- Прохождение всех тестов перед созданием Pull Request:
  ```bash
  go test -v ./...
  ```
- Форматирование кода через `gofmt` или `goimports`.

## Как отправить изменения:
1. Создайте форк репозитория и создайте ветку для фичи: `git checkout -b feature/my-feature`.
2. Внесите изменения и добавьте тесты.
3. Откройте Pull Request с подробным описанием решаемой задачи.
